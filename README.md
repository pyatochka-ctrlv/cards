# 💡 Генератор винаходів

Статичний вебзастосунок для онлайн-уроку (LetMe/teens, 9–10 років): дві колоди по 12 карток —
«ЩО ЗА ВИНАХІД?» (предмети) і «ЩО ВІН ВМІЄ?» (суперздібності). Дитина називає два номери,
вчителька відкриває картки — і з'являється ідея винаходу для пітчу.

Один файл `index.html`, без збірки. Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Інструкція для вчительки

1. Відкрийте сторінку в окремій вкладці браузера й у Google Meet оберіть «Показати екран» → «Вкладка» (так звук перевертання теж буде чути; вимкнути його — кнопка 🔊).
2. Попросіть дитину назвати два номери: «Перша колода — 5, друга — 9». Клацніть ці картки. Хто не хоче обирати — натисніть «🎲 Випадково».
3. Коли відкриються обидві картки, з'явиться панель із фразою-винаходом. Запитайте назву винаходу й впишіть її (необов'язково). Підказка «Ракета» допоможе дитині побудувати виступ.
4. Натисніть «📋 Скопіювати винахід», щоб вставити текст у пульт сцени. Хрестик × ховає панель, якщо треба ще раз показати картки.
5. Для наступної дитини — «🙋 Новий винахідник»: картки закриються, використані стануть напівпрозорими з ✓ (їх усе одно можна обрати). «🔀 Перемішати колоди» повертає всі картки й міняє їхні місця.

## Як редагувати

- **Картки** — масиви `DECK_INVENTIONS` і `DECK_POWERS` у `<script>` в `index.html`.
  Предмет: `{ emoji, name, gender: 'ч' | 'ж' | 'с' }`.
  Здібність: `{ emoji, text: '…' }` або, якщо слово змінюється за родом, `{ emoji, text: { ч: '…', ж: '…', с: '…' } }`.
- **Кольори й шрифти** — CSS-змінні в блоці `:root` на початку файлу.
